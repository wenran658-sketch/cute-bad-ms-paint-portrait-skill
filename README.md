# Cute Bad MS-Paint Portrait Skill

A small open-source prompt/skill for generating intentionally crude but cute old-computer-paint-style portraits.

The main design rule is simple:

> **Make the drawing bad, not the person.**

## What it does

It turns a portrait or couple photo into something that feels like:

- old Windows Paint
- drawn with a mouse
- chunky bitmap edges
- rough scribbled fills
- low-resolution pixel awkwardness
- “looks like them, but somehow everything is a little off”

It also strongly prefers preserving the original hairstyle unless the user explicitly asks for a change.

## Files

- `SKILL.md` — the full reusable skill
- `LICENSE` — MIT License
- `QUICKSTART.md` — short usage examples

## Quick use

Upload a photo and say:

> Use the Cute Bad MS-Paint Portrait skill. Keep the original hairstyle.

Then paste or attach the contents of `SKILL.md` into the system / custom instruction / agent skill area of the tool you use.
